# Blog API

A blog API: posts, comments, tags and author-scoped permissions.

## Run

```bash
npm install
npm start
```
The API runs on **http://localhost:5003** (health check at `/health`). Requires Node 22.5+.

## Built with

Node.js, Express, built-in SQLite (`node:sqlite`)
